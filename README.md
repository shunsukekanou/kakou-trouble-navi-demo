# 加工トラブル原因ナビ

加工の不具合（チッピング・面粗度不良・寸法ズレ・ビビリ振動・バリ）を、現象をタップして3つの質問に答えるだけで、原因の候補と点検の順番にたどり着くWebアプリです。過去の不適合・ヒヤリ・ハット事例が原因ごとに紐づき、同じ原因が重なった所を「作業標準書の改訂ポイント案」としてA4で出力できます。

- データベース・サーバー不要の静的Webアプリ（React + Vite + TypeScript）
- 事例は、この端末のブラウザ（localStorage）の中だけに保存します。外部への通信・送信はしません。
- 初期の事例（20件）と原因の候補は、架空の金属加工現場を想定した見本です。原因・点検の順番は一般的な目安で、実際の現場では自社の標準書と実績を優先します。

## 開発
```
npm install
npm run dev          # 開発用
npm run build:pages  # docs/ に公開用を作る（GitHub Pages: main の /docs）
```
